# Smart Home Autonomous Robot Simulation 🤖

An autonomous mobile robot simulation developed using **Webots** and **Python** to navigate and operate within a simulated indoor smart home environment.

## 🚀 About the Project
This project focuses on implementing autonomous navigation, sensor data processing, and obstacle avoidance logic for a mobile robot inside a controlled indoor smart home setting. 

## 🛠️ Tech Stack & Tools
* **Simulation Environment:** Webots
* **Programming Language:** Python
* **Core Concepts:** Autonomous Navigation, Sensor Integration, Obstacle Avoidance
